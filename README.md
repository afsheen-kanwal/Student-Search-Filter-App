# 🎓 Class Students Directory

A responsive student directory built with HTML, CSS and vanilla JavaScript. Student data is stored in a JavaScript object and rendered dynamically as cards.

## ✨ Features
- Dynamic cards generated from a JavaScript object
- Live search by student name
- Age range filter (20-22, 23-25, 26+), works together with search
- "No student found" message
- Fade-in animations and hover effects
- Student counter that updates with filters
- Responsive Flexbox layout

## 🛠 Technologies
- HTML5
- CSS3 (Flexbox, animations, gradients)
- JavaScript (ES6)
